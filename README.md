# Mirela Finanças V5.1

Aplicativo financeiro pessoal estático, sem Supabase. Os dados ficam no armazenamento local do navegador.

## Novidades V5.1
- limites mensais por categoria
- alertas em 70%, 90% e 100%+
- orçamento por categoria editável
- categorias com ícones
- criação de novas categorias
- contas e lançamentos
- salário configurável por percentuais
- cálculo automático de salário líquido, adiantamento e 5º dia útil
- análise estratégica
- backup e importação

## GitHub Pages
1. Crie um repositório público.
2. Envie `index.html`, `app.js`, `style.css`, `manifest.webmanifest` e `README.md`.
3. Settings > Pages > Deploy from a branch > `main` > `/ (root)` > Save.
4. Abra o endereço gerado pelo GitHub Pages.

Os dados são locais ao navegador. Use Exportar Backup regularmente se quiser uma cópia.
